Q1 — LIMITATIONS OF EXISTING TOOLS THAT MINDCANVAS SOLVES
================================================================

ROAM RESEARCH & OBSIDIAN:
- Require MANUAL link creation — users must explicitly tag and connect notes
- No automated semantic understanding of content relationships
- Cannot process external web content automatically
- Scalability fails as note count grows — manually linking hundreds of pages is impractical
- Designed for user-created notes, not browsing-history-scale web ingestion
- No quality scoring, summarisation, or topic extraction built-in

BROWSER BOOKMARKS / HISTORY:
- Flat, unstructured list with no topic grouping or semantic clustering
- No concept of "these two pages are about the same thing"
- Zero natural-language query capability
- No quality scoring, summarisation, or topic extraction
- Cannot answer "what have I read about machine learning?"
- No connection discovery between related content

GOOGLE'S KNOWLEDGE GRAPH (web-scale systems):
- Covers public world knowledge, NOT personalised to your specific browsing journey
- No individual learning history, no personal context
- Cannot be queried conversationally against your own content
- Requires massive infrastructure — not deployable locally

COMPARISON TABLE:

Feature                     | Roam/Obsidian | Browser History | Google KG | MindCanvas
----------------------------+---------------+-----------------+-----------+-----------
Auto semantic clustering    | No            | No              | Yes       | YES
Personal browsing ingestion | No            | Yes (flat)      | No        | YES
Natural language queries    | No            | No              | Limited   | YES

Connection discovery        | Manual        | No              | N/A       | YES (AI)

WHAT MINDCANVAS DIRECTLY SOLVES:
1. Automates link/connection creation using GPT-4.1-mini (no manual effort)
2. Converts passive browsing history into an active searchable knowledge graph
3. Enables conversational querying of personal knowledge via RAG chatbot
4. Groups related content semantically even when user doesn't tag anything
5. Surfaces forgotten content via recommendations and trending topics
6. Keeps all data local — no cloud sync, no third-party data exposure
7. Deduplicates repeated content visits via URL + content hash

class ChatRequest(BaseModel):
    message: str
    conversation_history: List[ChatMessage] = Field(default_factory=list)
    use_rag: bool = True
    max_context_items: int = Field(default=5, ge=1, le=MAX_CONTEXT_ITEMS)
    similarity_threshold: float = Field(default=0.3, ge=MIN_SIMILARITY_THRESHOLD, le=1.0)
    conversation_id: Optional[str] = None

class ChatResponse(BaseModel):
    response: str
    sources: List[Dict[str, Any]] = Field(default_factory=list)
    confidence: float = 0.0
    processing_time: float = 0.0
    tokens_used: int = 0
    conversation_id: str = ""
    rag_used: bool = False
    context_count: int = 0

--- CLASS INITIALIZATION ---

class RAGChatbot:
    def __init__(self, db, openai_key: Optional[str] = None):
        if not openai_key:
            raise ValueError("OpenAI API key is required for RAG chatbot")

        self.db = db
        self.openai_api_key = openai_key

        model_name = os.getenv("OPENAI_MODEL", "gpt-4o-mini")
        if model_name not in VALID_OPENAI_MODELS:
            logger.warning(f"Model '{model_name}' not in validated list, using gpt-4o-mini")
            model_name = "gpt-4o-mini"

        self.llm = ChatOpenAI(
            model=model_name,
            temperature=0.3,
            api_key=openai_key,
            request_timeout=30,
            max_retries=2
        )

        self.non_rag_prompt = """You are MindCanvas AI, a helpful assistant for exploring personal knowledge.
The user asked a question, but no relevant documents were found in their knowledge base.
Guidelines:
1. Answer based on general knowledge since no specific information was found in their MindCanvas.
2. DO NOT invent sources or pretend to have context from their knowledge base.
3. Be conversational and helpful.
4. Suggest adding related content to their knowledge base for better answers in the future."""

        self.rag_system_prompt = """You are MindCanvas AI, an intelligent assistant that helps users explore
and understand their personal knowledge base.
GUIDELINES:
1. Primary Source: Prefer information from the Context section when relevant and helpful.
2. Cite Sources: When drawing from the context, cite sources as [Source: Title].
3. Supplement with Knowledge: If the context is partial or missing details, supplement with
   general knowledge — but clearly distinguish what comes from the user's saved content vs. yours.
4. Be a Synthesizer: Connect ideas across sources, summarize findings, provide actionable insights.
5. Be Honest: If nothing relevant is in the context, say so, but still try to answer helpfully.
6. Be Conversational: Maintain a helpful, concise, and engaging tone.
The context from their knowledge base follows:"""

        self.conversation_memories: Dict[str, _SimpleConversationMemory] = {}

--- MAIN PIPELINE ---

async def process_chat_request(self, request: ChatRequest) -> ChatResponse:
    """Main chat processing pipeline."""
    start_time = datetime.now()
    conversation_id = request.conversation_id or f"chat_{int(start_time.timestamp())}"

    try:
        # Initialize or get in-memory conversation
        if conversation_id not in self.conversation_memories:
            self.conversation_memories[conversation_id] = _SimpleConversationMemory()
        memory = self.conversation_memories[conversation_id]

        # Sync conversation history from client (max 20 messages)
        if request.conversation_history:
            memory.clear()
            for msg in request.conversation_history[-MAX_CONVERSATION_HISTORY:]:
                if msg.role == "user":
                    memory.chat_memory.add_user_message(msg.content)
                elif msg.role == "assistant":
                    memory.chat_memory.add_ai_message(msg.content)

        # RAG Retrieval
        context_items: List[KnowledgeContext] = []
        rag_used = False

        if request.use_rag:
            context_items = await self._retrieve_relevant_context(
                request.message,
                request.max_context_items,
                request.similarity_threshold,
            )
            rag_used = len(context_items) > 0

        # Generate LLM response
        response_text, tokens_used, confidence = await self._generate_response(
            request.message, context_items, memory,
        )

        processing_time = (datetime.now() - start_time).total_seconds()

        return ChatResponse(
            response=response_text,
            sources=[self._format_source(item) for item in context_items],
            confidence=confidence,
            processing_time=processing_time,
            tokens_used=tokens_used,
            conversation_id=conversation_id,
            rag_used=rag_used,
            context_count=len(context_items)
        )

    except Exception as e:
        raise HTTPException(status_code=500, detail=f"Chat processing failed: {str(e)}")

--- CONTEXT RETRIEVAL (vector search → keyword fallback) ---

async def _retrieve_relevant_context(self, query, max_items, threshold):
    try:
        # Primary: vector similarity search via pgvector
        results = await self.db.semantic_search(query, max_items, threshold)
        context_items = []

        for result in results:
            summary = result.get("summary", "") or ""
            if not summary or len(summary) < 5:
                continue
            context_items.append(KnowledgeContext(
                content=summary,
                title=result.get("title", "Untitled"),
                url=result.get("url", ""),
                content_type=result.get("content_type", "Unknown"),
                quality_score=float(result.get("quality_score", 0.0)),
                similarity=float(result.get("similarity", 0.0)),
                summary=summary,
            ))

        if context_items:
            return context_items

        # Fallback: keyword overlap scoring when vector search returns nothing
        return await self._keyword_fallback(query, max_items)

    except Exception as e:
        return await self._keyword_fallback(query, max_items)

--- KEYWORD FALLBACK ---

async def _keyword_fallback(self, query, max_items):
    items = await self.db.get_top_content(100)
    stop_words = {
        'the','a','an','is','are','was','were','in','on','at','to','for',
        'of','and','or','my','i','me','did','what','how','when','where',
        'which','who','have','has','been','about','with','from','this',
        'that','be','do','does','some','any','all','their','they','we',
        'you','your','tell','show','find','get','give','let','know',
    }
    query_words = {w for w in query.lower().split() if len(w) > 2 and w not in stop_words}

    scored = []
    for item in items:
        title   = item.get('title', '') or ''
        summary = item.get('summary', '') or ''
        topics  = ' '.join(item.get('key_topics', []) or [])
        blob    = f"{title} {summary} {topics}".lower()

        score   = sum(1 for w in query_words if w in blob) if query_words else 0
        quality = item.get('quality_score', 5) or 5
        scored.append((score, quality, item))

    scored.sort(key=lambda x: (x[0], x[1]), reverse=True)

    context_items = []
    for score, quality, item in scored[:max_items]:
        summary = item.get('summary', '') or item.get('title', '')
        if not summary:
            continue
        sim = min(0.9, 0.3 + score * 0.1) if query_words else 0.3
        context_items.append(KnowledgeContext(
            content=summary,
            title=item.get('title', 'Untitled'),
            url=item.get('url', ''),
            content_type=item.get('content_type', 'Unknown'),
            quality_score=float(quality),
            similarity=sim,
            summary=summary,
        ))
    return context_items

--- RESPONSE GENERATION (LLM call with system prompt) ---

async def _generate_response(self, query, context_items, memory):
    if not context_items:
        # No context found — general knowledge path
        messages = [
            SystemMessage(content=self.non_rag_prompt),
            HumanMessage(content=f"Question: {query}")
        ]
    else:
        # RAG path — inject context into prompt
        context_str = self._build_context_string(context_items)
        messages = [
            SystemMessage(content=self.rag_system_prompt),
            *memory.chat_memory.messages,        # inject conversation history
            HumanMessage(content=f"Context:\n{context_str}\n\n---\n\nQuestion: {query}")
        ]

    # Call OpenAI LLM asynchronously
    response = await self.llm.ainvoke(messages)
    response_text = response.content

    # Extract token usage from response metadata
    usage = getattr(response, "usage_metadata", None) or {}
    tokens_used = (
        usage.get("total_tokens") or
        (usage.get("input_tokens", 0) + usage.get("output_tokens", 0)) or 0
    )

    # Confidence = weighted average of similarity scores + quality + citation count
    confidence = self._calculate_confidence(context_items, response_text)

    # Update in-memory conversation history
    memory.chat_memory.add_user_message(query)
    memory.chat_memory.add_ai_message(response_text)

    return response_text, int(tokens_used), float(confidence)

async def _ai_graph_structure(items: list) -> dict:
    """
    Single GPT-4.1-mini call that produces BOTH cluster assignments AND edges.
    Uses JSON Mode for structured, parseable output.

    Returns:
        {
            "id_to_cluster": { str(id): (cluster_name, cluster_int_id) },
            "edges":          [ {"source": str, "target": str, "reason": str} ]
        }
    """
    if not OPENAI_API_KEY:
        return {"id_to_cluster": {}, "edges": []}

    # Build lightweight node descriptions for the prompt
    node_descriptions = []
    for item in items:
        topics = item.get('key_topics') or []
        summary = (item.get('summary') or '')[:120].strip()
        node_descriptions.append({
            "id": str(item['id']),
            "title": item.get('title', ''),
            "summary": summary,
            "topics": topics[:5],
            "type": item.get('content_type', ''),
        })

    prompt = f"""You are a knowledge graph architect. Given these content nodes, decide:
1. How to cluster them into meaningful semantic groups.
2. Which pairs of nodes should be connected by an edge.

CLUSTERING RULES:
- Create 3 to 12 clusters based on distinct themes.
- Cluster name: short label (2-4 words), e.g. "Python Programming", "Machine Learning".
- Every node must be in exactly one cluster.
- Base decisions on title + summary, not just keywords.
- Closely related nodes (e.g. two Python tutorials) MUST share a cluster.

EDGE RULES:
- Only connect nodes that share a meaningful semantic relationship.
- Aim for 2-4 edges per node on average — not too sparse, not a hairball.
- Prefer connecting nodes within the same cluster, but cross-cluster edges are fine when genuinely related.
- Do NOT add edges just because nodes share a generic topic like "programming" or "learning".
- Each edge must have a short reason (5-10 words).

Nodes:
{json.dumps(node_descriptions, indent=2)}

Respond with a single JSON object:
{{
  "clusters": [
    {{
      "name": "Cluster Name",
      "node_ids": ["1", "5", "12"]
    }}
  ],
  "edges": [
    {{
      "source": "1",
      "target": "5",
      "reason": "Both cover Python data structures"
    }}
  ]
}}"""

    client = OpenAI(api_key=OPENAI_API_KEY)
    response = await asyncio.to_thread(
        client.chat.completions.create,
        model="gpt-4.1-mini-2025-04-14",
        messages=[{"role": "user", "content": prompt}],
        response_format={"type": "json_object"},   # JSON Mode — guaranteed valid JSON
        temperature=0.0,                            # Deterministic output
        max_tokens=4000,
    )

    result = json.loads(response.choices[0].message.content)
    clusters_list = result.get("clusters", [])
    edges_list    = result.get("edges", [])

    # Build id_to_cluster mapping
    id_to_cluster = {}
    for idx, cluster in enumerate(clusters_list, 1):
        name = cluster.get("name", f"Cluster {idx}")
        for node_id in cluster.get("node_ids", []):
            id_to_cluster[str(node_id)] = (name, idx)

    # Validate edges — only keep pairs where both node IDs exist
    valid_ids = set(id_to_cluster.keys())
    valid_edges = [
        e for e in edges_list
        if str(e.get("source")) in valid_ids
           and str(e.get("target")) in valid_ids
           and str(e.get("source")) != str(e.get("target"))
    ]

    return {"id_to_cluster": id_to_cluster, "edges": valid_edges}

--- FALLBACK: TOPIC-SPECIFICITY CLUSTERING (no API key needed) ---

def _topic_specificity_clustering(items: list) -> dict:
    """
    Step 1: Normalize topics to canonical forms
            ("Python Programming" + "Python Data Types" both map to "Python")
    Step 2: Frequency analysis — topics in >= 2 nodes form cluster seeds
    Step 3: Assign each node to its most specific (least globally common) seed topic
    Step 4: Merge singleton clusters into best alternative group
    Returns: dict of str(id) -> (display_cluster_name, cluster_int_id)
    """
    n = len(items)
    if n == 0:
        return {}

    # Count canonical topic frequency across all items
    topic_counts = Counter()
    for item in items:
        seen = set()
        for t in (item.get('key_topics') or []):
            canonical = norm_map.get(t.lower().strip(), t.lower().strip())
            if canonical not in seen:
                topic_counts[canonical] += 1
                seen.add(canonical)

    # Topics appearing in 2 to 70% of nodes form cluster seeds
    min_support = 2
    max_support = max(2, int(n * 0.70))
    group_topics = {t for t, c in topic_counts.items()
                    if min_support <= c <= max_support}

    # Assign each node to its most representative group topic
    id_to_cluster = {}
    for item in items:
        sid = str(item['id'])
        node_canonicals = []
        seen = set()
        for t in (item.get('key_topics') or []):
            canonical = norm_map.get(t.lower().strip(), t.lower().strip())
            if canonical in group_topics and canonical not in seen:
                node_canonicals.append(canonical)
                seen.add(canonical)

        if node_canonicals:
            # Pick highest-frequency topic (most representative cluster)
            best = max(node_canonicals, key=lambda t: (topic_counts[t], t))
            id_to_cluster[sid] = best
        else:
            # No group-forming topic — use first raw topic or content_type
            raw = item.get('key_topics') or []
            if raw:
                id_to_cluster[sid] = norm_map.get(raw[0].lower().strip(), raw[0].lower().strip())
            else:
                id_to_cluster[sid] = item.get('content_type', 'General').lower()

    # Merge singletons into nearest multi-node cluster
    cluster_sizes = Counter(id_to_cluster.values())
    singletons = {c for c, sz in cluster_sizes.items() if sz == 1}
    if singletons:
        for item in items:
            sid = str(item['id'])
            if id_to_cluster.get(sid) in singletons:
                node_canonicals = [
                    norm_map.get(t.lower().strip(), t.lower())
                    for t in (item.get('key_topics') or [])
                ]
                alternatives = [t for t in node_canonicals
                                if t != id_to_cluster[sid] and t in group_topics]
                if alternatives:
                    id_to_cluster[sid] = max(alternatives, key=lambda t: (topic_counts[t], t))

    # Assign integer IDs to canonical cluster names
    unique_clusters = sorted(set(id_to_cluster.values()))
    cluster_name_to_id = {name: i + 1 for i, name in enumerate(unique_clusters)}

    return {
        sid: (display_name.get(name, name.title()), cluster_name_to_id[name])
        for sid, name in id_to_cluster.items()
    }

async def generate_embedding(self, text: str, use_openai: bool = True) -> List[float]:
    """Generate a 384-dim embedding using SentenceTransformer (local, free)."""
    target_dimension = 384
    text_preview = text[:80] + "..." if len(text) > 80 else text
    try:
        if self.st_embedder:
            # Run in thread pool — encode() is synchronous and CPU-bound
            embedding = await asyncio.to_thread(self.st_embedder.encode, text)
            return embedding.tolist()
        logger.warning(f"No embedder available for '{text_preview}'")
        return [0.0] * target_dimension      # zero vector fallback
    except Exception as e:
        logger.error(f"Embedding generation failed: {e}")
        return [0.0] * target_dimension      # zero vector on any error

async def semantic_search(self, query: str, limit: int = 20, threshold: float = 0.3):
    """Vector similarity search using pgvector cosine distance operator <=>"""
    query_embedding = await self.generate_embedding(query)

    rows = await conn.fetch("""
        WITH scored AS (
            SELECT id, url, title, summary, content_type, key_topics, quality_score,
                   1 - (embedding <=> $1) AS similarity
                   -- <=> is pgvector cosine distance
                   -- similarity = 1 - distance (1.0 = identical, 0.0 = orthogonal)
            FROM processed_content
            WHERE embedding IS NOT NULL
        )
        SELECT * FROM scored
        WHERE similarity > $2          -- threshold filter (default 0.3)
        ORDER BY similarity DESC
        LIMIT $3
    """, query_embedding, threshold, limit)

    return [
        {
            "id": r["id"],
            "url": r["url"],
            "title": r["title"],
            "summary": r["summary"],
            "content_type": r["content_type"],
            "key_topics": self._parse_topics(r["key_topics"]),
            "quality_score": r["quality_score"],
            "similarity": round(float(r["similarity"]), 3),
        }
        for r in rows
    ]

KEY ARCHITECTURAL DECISIONS (important context for paper)
================================================================

1. SINGLE LLM CALL FOR BOTH CLUSTERS AND EDGES
   The _ai_graph_structure() function makes ONE GPT-4.1-mini call using JSON Mode
   that returns both cluster assignments AND the edge list simultaneously.
   Benefit: Saves API cost, ensures cluster-edge consistency, deterministic (temperature=0).

2. DUAL EMBEDDING STRATEGY
   - SentenceTransformer all-MiniLM-L6-v2: free, local, 384-dim, used for EVERY item
   - OpenAI GPT-4.1-mini: paid, used ONLY for high-level clustering (not per-item)
   Benefit: Low cost, no dependency on OpenAI for core functionality.

3. GRACEFUL DEGRADATION CHAIN
   Clustering:    AI clustering → topic-specificity fallback → content-type grouping
   Chat context:  vector search → keyword overlap fallback → empty context (general LLM)
   Benefit: System always produces output even without API key or embeddings.

4. PRESET LAYOUT, NO PHYSICS SIMULATION
   Graph positions computed mathematically (phyllotaxis golden-angle + ring formula).
   Layout type is 'preset' — no fcose physics simulation.
   Benefit: Stable, readable cluster separation; no jitter or drift on refresh.

5. PRIVACY-FIRST ARCHITECTURE
   All embeddings and content stored locally in Docker PostgreSQL.
   OpenAI receives only titles + 120-char summaries for clustering.
   Raw page HTML/content never sent to any external API.
   Chrome extension sends data only to localhost.

6. CONTENT PIPELINE USES TWO DIFFERENT GPT MODELS
   - GPT-4.1-nano (batch, JSON Mode): per-item extraction (title, summary, topics, quality score)
     → cheap, fast, structured
   - GPT-4.1-mini (single call, JSON Mode): graph-level clustering + edge generation
     → higher capability needed for semantic graph reasoning

7. IVFFLAT INDEX FOR SCALABLE VECTOR SEARCH
   The PostgreSQL ivfflat index with lists=100 gives approximate nearest-neighbor search.
   Scales to ~1 million vectors while keeping query latency under 20ms.
   Exact threshold: similarity > 0.3 (cosine similarity, configurable per request).

8. CONVERSATION MEMORY IS IN-MEMORY ONLY
   Each conversation_id maps to a _SimpleConversationMemory object stored in a Python dict.
   Max 20 messages retained per conversation.
   Lost on server restart — no persistent conversation storage.
