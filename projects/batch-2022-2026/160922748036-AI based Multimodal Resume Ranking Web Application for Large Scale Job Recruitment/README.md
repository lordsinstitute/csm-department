## 📌 Overview

This project is a **Django-based web application** that uses **Machine Learning techniques** to automatically analyze and rank resumes based on job requirements.

It helps recruiters:
- Save time in manual screening
- Identify the best candidates quickly
- Make smarter hiring decisions

## 🚀 How to Run the Project

### 1. Clone the Repository
```bash
git clone https://github.com/your-username/your-repo-name.git
cd your-repo-name
```

### 2. Install Dependencies
```bash
pip install -r requirements.txt
```

### 3. Run Server
```bash
python manage.py runserver
```

### 4. Open in Browser
```
http://127.0.0.1:8000/
```
