Medical Chatbot using Gamma LLMv2 with BERT Comparison



📌 Project Overview



This project presents an intelligent medical chatbot designed to provide basic healthcare-related information based on user queries. The system leverages advanced Natural Language Processing (NLP) techniques using Gamma LLMv2 and compares its performance with BERT-based models.



The chatbot is implemented as a web application using the Django framework, ensuring scalability, modularity, and efficient handling of user interactions. It demonstrates how AI can be applied in the healthcare domain to assist users with preliminary medical guidance.



🎯 Objectives



\* Develop an AI-based chatbot for medical query handling

\* Implement Gamma LLMv2 for response generation

\* Compare performance with BERT models

\* Provide a user-friendly web interface

▶️ How to Run the Project



1\. Clone the repository

2\. Navigate to the project folder

3\. Install dependencies:

&#x20;  pip install -r requirements.txt

4\. Run the server:

&#x20;  **python manage.py runserver**

5\. Open browser and go to:

&#x20;  http://127.0.0.1:8000/



📊 Dataset Information



This project utilizes medical knowledge derived from the Gale Encyclopedia.



Due to copyright and licensing restrictions, the dataset (PDF) is not included in this repository. To fully run the chatbot with complete functionality, the dataset must be added manually.
